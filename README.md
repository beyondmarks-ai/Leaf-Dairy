# Leaf Dairy

Leaf Dairy is a cinematic Windows diary and story-writing dashboard built with C# and .NET 8 WPF.

## Run

```powershell
cd DearDairy
dotnet run
```

## Build

```powershell
cd DearDairy
dotnet build
```
